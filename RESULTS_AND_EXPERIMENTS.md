## Important notes

- The Task 3 timing result depends on the computer and current system load. Do not copy the example timing as a guaranteed result.
- The Monte Carlo result is an estimate from random sampling. A different random seed or sample count can produce a slightly different percentage.
- For Tasks 5, 9, 10, 11, 12, 13, 14, 17, 18, 19 and 20, the experiment guidance describes the expected direction or type of change. Run the altered program and record the actual result before submitting.
- The lecturer asks for an individual GitHub repository and documentation submitted through VLMS. A ZIP file alone is not the GitHub submission.
